# Install StudySnap on Android

[**Download StudySnap 1.1.0 APK**](https://github.com/hosannaute/studysnap-pdf-server/raw/refs/heads/main/downloads/StudySnap.apk)

1. Download the APK using your phone's browser. If GitHub opens a file page, select **Download raw file**.
2. Open the downloaded file using Files or your browser's Downloads list.
3. Allow installation from that source when Android prompts, then install StudySnap.
4. Open the app, allow notifications, import a typed PDF, and enable that subject's reminders. Use **Send test reminder** to check notification access immediately.

Requires Android 8.0+. This is a debug-signed testing build; no Expo Go is needed. Android battery policy can delay reminders. Real-phone delivery still needs testing. The app has no internet permission.

The matching source is in `android/`. `StudySnap.apk.sha256` verifies the downloaded file. A SHA-256 checksum checks download integrity; it is not a production signing certificate.
